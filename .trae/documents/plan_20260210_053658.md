### 🔍 Analisis Kondisi Saat Ini

Proyek ini menggunakan arsitektur yang solid (**Clean Architecture + Bloc**), namun ada beberapa bagian kritikal yang belum selesai diimplementasikan (placeholder) atau memiliki logika yang rentan error (swallow errors).

#### 1. Konfigurasi Environment (CRITICAL)
- **Status:** 🔴 **Rusak / Tidak Jalan**
- **Masalah:** File `lib/core/constants/env.dart` masih berisi nilai placeholder (`your-project-url`).
- **Dampak:** Aplikasi akan crash atau stuck di *splash screen* karena gagal terhubung ke Supabase.

#### 2. Sinkronisasi Data (Sync Service)
- **Status:** ⚠️ **Rentan Error**
- **Masalah:** `SyncService` menangkap error dengan `catch (e)` tapi hanya melakukan `debugPrint`. `SyncCubit` hanya memantau status loading (`bool`).
- **Dampak:** Jika sinkronisasi gagal (misal internet tidak stabil), pengguna tidak akan tahu. Data lokal dan server bisa tidak konsisten tanpa peringatan.

#### 3. Autentikasi Offline
- **Status:** ⚠️ **Belum Lengkap**
- **Masalah:** Di `AuthBloc`, logika login offline menggunakan "Fake User" atau state yang tidak lengkap.
- **Dampak:** Saat offline, fitur yang membutuhkan data profil user (seperti nama/role di dashboard) mungkin akan error atau tampil kosong.

#### 4. Setup Database
- **Status:** ❓ **Perlu Konfirmasi**
- **Masalah:** Ada panduan SQL di `SUPABASE_SETUP.md` yang harus dijalankan manual di dashboard Supabase.
- **Dampak:** Fitur upload bukti transaksi dan sinkronisasi akan gagal (Permission Denied) jika RLS policies belum di-set.

### 🚀 Rencana Penyempurnaan (Implementation Plan)

Saya mengusulkan rencana perbaikan bertahap berikut:

#### Langkah 1: Konfigurasi Environment
- **Tindakan:** Saya akan meminta kredensial Supabase Anda (URL & Anon Key) untuk diupdate ke `lib/core/constants/env.dart`.
- **Alternatif:** Jika Anda belum memilikinya, saya akan memandu Anda untuk membuatnya di Supabase.

#### Langkah 2: Perbaikan `SyncService` & `SyncCubit`
- **Tindakan:**
    1.  Ubah `SyncService.syncData()` agar mengembalikan status keberhasilan/kegagalan (bukan void).
    2.  Upgrade `SyncCubit` dari `Cubit<bool>` menjadi `Cubit<SyncState>` yang bisa membawa pesan error.
    3.  Tambahkan mekanisme notifikasi (SnackBar) di UI saat sinkronisasi gagal atau berhasil.

#### Langkah 3: Penyempurnaan Auth Offline
- **Tindakan:**
    1.  Modifikasi `AuthOffline` state agar bisa menyimpan data user minimal (nama, email, role) yang diambil dari database lokal (`AuthLocalDatasource`).
    2.  Pastikan `AuthBloc` mengisi data tersebut saat fallback ke mode offline.

#### Langkah 4: Verifikasi Setup Database
- **Tindakan:** Saya akan meminta konfirmasi apakah Anda sudah menjalankan script SQL di `SUPABASE_SETUP.md`. Jika belum, saya akan memandu Anda.
